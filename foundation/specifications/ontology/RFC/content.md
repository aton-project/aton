# Request for Comments

## Status

Draft

## Definition

An RFC represents a formal engineering specification or proposal that defines rules, behavior, interfaces or other normative aspects of ATON.

## Role in ATON

This ontology concept defines a semantic category used by the ATON
Foundation.

The concept SHALL be interpreted consistently across the ATON kernel,
Foundation artifacts and tooling.
