# F-002 — Metadata semantics are incomplete

## Observation

The ADR defines metadata as information describing the artifact.

## Problem

The Engineering Knowledge Model does not yet define which metadata is
persisted and which metadata is derived.

## Recommendation

Clarify the normative semantics of engineering metadata.

## Assessment

### Decision

Accepted

### Rationale

The semantics of engineering metadata affect the Engineering Knowledge Model
as a whole and require a dedicated engineering discussion.
