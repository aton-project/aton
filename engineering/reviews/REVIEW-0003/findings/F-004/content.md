# F-004 — Engineering semantics of commits

## Observation

ADR-0003 requires engineering changes to be represented by Git commits.

## Problem

The engineering meaning of a commit is not defined.

## Recommendation

Define the engineering semantics associated with commits.

## Assessment

### Decision

Accepted

### Rationale

The engineering semantics of Git commits require a dedicated engineering
discussion and should not be introduced solely within ADR-0003.

Category: process
