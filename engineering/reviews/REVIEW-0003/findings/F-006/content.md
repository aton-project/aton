# F-006 — Git tooling compatibility scope

## Observation

ADR-0003 limits Git tooling compatibility to the Foundation.

## Problem

The same compatibility requirement should apply to all engineering artifacts.

## Recommendation

Clarify the scope of Git tooling compatibility.

## Assessment

### Decision

Accepted

### Rationale

Git tooling compatibility should apply consistently to all engineering
artifacts.

### Classification

Category: architecture

### Disposition

Direct Implementation

### Execution
