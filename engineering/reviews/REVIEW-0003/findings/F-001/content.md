# F-001 — Scope limited to the Foundation

## Observation

ADR-0003 defines Git as the version control system only for the Foundation.

## Problem

Git manages all engineering artifacts within ATON, not only Foundation
artifacts.

## Recommendation

Clarify the scope of the decision.

## Assessment

### Decision

Accepted

### Rationale

The architectural scope should consistently address all engineering artifacts,
not only the Foundation.

### Classification

Category: architecture

### Disposition

Direct Implementation

### Execution

Target: ADR-0003

Verification: Pending
