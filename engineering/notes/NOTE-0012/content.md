# NOTE-0012 — Engineering Metadata Semantics

## Context

The review of ADR-0005 identified that the semantics of engineering metadata
are not yet defined consistently.

---

## Problem Statement

The Engineering Knowledge Model distinguishes engineering content, metadata
and relationships, but the normative semantics of metadata remain undefined.

This affects interoperability, automated processing and consistent
interpretation across implementations.

---

## Questions

The engineering community should evaluate:

- What is engineering metadata?
- Which metadata is normative?
- Which metadata is informative?
- Which metadata belongs to entities?
- Which metadata belongs to artifacts?
- How should metadata evolve over time?

---

## Expected Outcome

Define the normative semantics of engineering metadata within the Engineering
Knowledge Model.
